# 点序 · 屏幕连点器

Windows x64 中文桌面连点器。使用 WPF / .NET 10，最终发布为自包含单文件 EXE。

## 直接使用

打开 release/点序.exe。无需安装、无需单独安装 .NET 运行环境。
详见 docs/使用说明.txt。默认 F6 启停、F8 紧急停止；运行时真实鼠标快速双击左键也可停止。

- 固定单点或多点顺序循环；每点独立左/右键与等待时间。
- 持续运行或指定实际点击总数；精确达数即停。
- 全局快捷键可修改；冲突有提示；安全控制未就绪不允许开始。
- 全屏选点拦截选取点击，支持 Esc/右键取消。
- 自动最小化可关闭；设置自动保存，绝不自动开始。

## 开发结构

- src/DianXu.Core：不可变点击计划、可取消执行器、真实双击判定、原子设置读写。
- src/DianXu.App：WPF 中文界面、原生 SendInput、低级鼠标钩子、全局快捷键、PerMonitorV2 DPI 感知。
- tests/DianXu.Tests：无第三方测试框架的自动化断言，失败返回非零退出码。
- scripts/build.ps1：测试、自包含发布、生成源码 ZIP 和 SHA256。
- scripts/New-Icon.ps1：使用 Windows System.Drawing 生成多尺寸应用图标，无图像包依赖。

## 编译与打包

需要 Windows x64 和 .NET 10 SDK（只有运行时不够）。可使用系统 SDK，或解压 SDK 到 .tools/dotnet。
在项目文件夹中运行 PowerShell：

    .\scripts\build.ps1

仅运行逻辑测试：

    .\scripts\build.ps1 -TestOnly

输出 release/点序.exe、使用说明.txt、点序-源码.zip、SHA256.txt。
首次自包含发布需要从 NuGet 下载微软运行时包，后续使用缓存。无业务第三方 NuGet 依赖。
下载的 SDK、运行时包和构建缓存均不包含在源码包中。

## 桌面集成检查

    .\release\点序.exe --diagnostics "C:\完整路径\诊断输出目录"

会短暂显示自己的测试窗口，仅在确认目标仍为该窗口后发送输入；完成后自动关闭并恢复鼠标。
输出主界面/空态/编辑界面 PNG、desktop-tests.txt、environment.json。
实际验证：左右键顺序、精确总数、每次点击的物理像素坐标、注入标记过滤、长等待取消、不同焦点窗口下的 F6/F8、快捷键冲突回滚，以及完整主窗口的启动/停止、最小化恢复、排序保存、选点取消和运行中退出。
当前版本通过 65 项逻辑断言与 21 项桌面检查；验证范围与未验证项见 docs/测试结果.md。
不通过模拟输入冒充真实硬件测试；真实物理双击、多显示器混合缩放、提升权限目标由用户环境复核。

## 设计注意

1. 注入事件通过 LLMHF_INJECTED/LOWER_IL 标志与应用 ExtraInfo 标记排除；真实左键按下才进入双击检测。
2. 停止双击不比较坐标：软件本身可能在两次真实按下之间移动光标。
3. SendInput 在工作线程执行，不在其调用期间持有钩子回调也需要的锁，避免互相等待。
4. 等待使用可取消任务，不用阻塞 UI 的 Sleep；运行计划复制为快照；任务未结束时拒绝重复启动。
5. UI 统计以 100ms 定时刷新，避免高频点击导致消息队列拥堵、鼠标钩子失去响应。
6. 选点和实际发送都使用物理屏幕坐标，绝对移动覆盖虚拟桌面，并验证坐标属于已连接显示器。
7. 设置保存在 %LOCALAPPDATA%/DianXu/settings.json，先写临时文件再替换，损坏时尽量保留备份。
8. 程序仅保证已验证场景，不规避安全桌面、UIPI 或软件自身输入保护。

## 构建依据

原生接口依据 Microsoft Learn 的 SendInput、MSLLHOOKSTRUCT、LowLevelMouseProc、RegisterHotKey 文档；打包采用 .NET 自包含单文件发布。
本项目不附带代码签名证书，不自动提权、不联网、不注入其他进程。
