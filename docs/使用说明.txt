点序 · 屏幕连点器 v1.0
======================

一、打开软件
双击“点序.exe”即可运行，不用安装，也不用另行安装 .NET 运行环境。
这是 Windows 64 位版本。首次启动可能需要一点时间解压内置组件。
软件不需要联网，不会自动开始点击。

二、添加位置
1. 点击“添加位置”。主窗口会临时隐藏。
2. 将鼠标移到屏幕上的目标位置，单击左键选取。
3. 选点时，右键或 Esc 可取消；选点点击会被拦截，不作为目标按钮的一次操作。
4. 在弹出的窗口中设置左键或右键，以及“点击后等待时间”。
5. 点击“保存位置”。重复这些步骤，可以添加多个位置。
6. 在列表中选择某行，可编辑、上移、下移、删除；双击列表项也能编辑。

三、设置执行方式
只有一个位置：在该位置反复点击。
有多个位置：按列表从上到下依次点击，末尾位置等待结束后回到第一个。
每个位置的等待时间独立设置，支持小数、秒和毫秒，范围为 1 毫秒到 24 小时。
“等待时间”指本次点击之后、下一次点击之前的等待，不是首次点击前的倒计时。
实际频率受 Windows 调度、电脑性能及目标程序响应影响，1 毫秒设置不代表保证每秒 1000 次。

四、停止条件
持续点击：一直运行，直到手动停止。
指定总次数：达到指定点击总数后停止。
左键或右键每点击一下计 1 次，不按循环轮数计算；每次开始重新计数。
例如，三个位置、总次数为 10，会执行三轮加第一个位置，然后直接停止。

五、开始与停止
默认 F6：开始 / 停止，切换到其他软件也有效。
默认 F8：紧急停止，等待时间很长时也能中断。
运行时，手动快速双击鼠标左键，也可以停止。
软件会过滤模拟鼠标事件，避免把自己的连续点击当作手动双击。
手动双击按系统双击时间窗口识别，不要求两次点击位置相同，以适应程序移动鼠标的情况。
注意：停止用的双击仍是真实鼠标输入，可能同时被目标程序收到。需要避免影响目标时，优先使用 F8。
界面右下角可以修改快捷键。如果提示快捷键被占用，请改用其他功能键。
软件不会在安全控制初始化失败或快捷键未就绪时启动点击。

六、避免遮挡目标
默认勾选“开始后最小化，避免遮挡目标”。停止后，窗口会恢复。
如果关闭这一选项，请自行把主窗口移离点击目标。
运行期间位置列表与设置暂时禁用，停止后可编辑。
空列表或不在当前显示器上的坐标不会开始点击。

七、保存与恢复
位置、顺序、等待时间、按键、停止条件及快捷键会自动保存在：
%LOCALAPPDATA%\DianXu\settings.json
下次启动恢复设置，但不自动开始。
设置损坏时会恢复安全默认值，并尽可能在原文件夹备份原文件。
在屏幕分辨率、缩放比例、显示器布局或目标窗口位置改变后，请重新确认点击位置。

八、范围与限制
目标是屏幕上可见的位置，不支持点击被遮挡或最小化窗口里的按钮。
不能保证所有软件都接受模拟输入。权限更高的窗口、系统安全界面或有特殊输入保护的软件可能无法操作。
如目标程序以管理员权限运行，请先确认是否确实需要相同权限；本软件不会自动请求提权。
本版在当前 Windows 64 位电脑完成了自动逻辑测试及自有测试窗口的实际输入测试。
真实鼠标硬件双击停止、多显示器混合缩放、不同权限目标窗口，仍需要在实际使用环境中复核。
没有开发者代码签名；如果出现系统安全提示，请核对文件来源，不要关闭系统整体安全保护。

建议先用少量次数和较长间隔，在不涉及付款、删除或发送消息的安全界面试用。
